# Rohan Reddy Yalam | Senior QA Automation Engineer

Premium portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, and React Router. Designed for recruiter-facing presentation with strong focus on automation, testing, and leadership.

## Features

- Modern glassmorphism UI with premium gradients
- Responsive layout for desktop, tablet, and mobile
- Dark/light theme toggle with persistent preference
- Animated section transitions using Framer Motion
- Reusable components and structured project architecture
- SEO metadata, robots.txt, and sitemap.xml
- GitHub Pages compatible deployment setup

## Tech Stack

- React + Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- React Icons

## Development

Install dependencies:

```bash
npm install
```

Run local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

This project is configured for GitHub Pages. The site uses React Router HashRouter mode for GitHub Pages compatibility.

Build output can be deployed with:

```bash
npm run deploy
```

If using GitHub Actions, the workflow in `.github/workflows/gh-pages.yml` will build and publish the site automatically.
